ChainVigil was an initial proof-of-concept for cross-channel money mule detection 
using NetworkX entity graphs and PyTorch Geometric GNN models. It executed static, 
fixed sequential API pipelines (/api/pipeline/run).

SECTION 2: HACKATHON PROBLEM STATEMENT & OBJECTIVES
--------------------------------------------------------------------------------
- Hackathon Track: Problem Statement 1 — AI-Powered Suspicious Activity Detection
- Business Goal: Build an intelligent, autonomous agent that learns from transaction 
  patterns, detects money laundering (Structuring, Smurfing, Rapid Cash-Out, Layering), 
  and provides explainable risk assessments with actionable escalation recommendations.
- Key Agentic Requirement:
  The agent MUST NOT follow a fixed sequential pipeline. It must parse natural language 
  queries, extract intent/filters/entities, and dynamically construct execution plans 
  invoking ONLY the tools required for that specific query.
- Strict Constraints:
  1. No restricted organization references (SG, Societe Generale, SocGen, SGGSC).
  2. Generic banking AML domain naming throughout.
  3. Public GitHub repo with full commit history created during hackathon window.
  4. Runnable local setup (FastAPI + React Vite), no mandatory cloud deployment.

SECTION 3: MULETRACE SYSTEM ARCHITECTURE & COMPONENTS
--------------------------------------------------------------------------------
Project Root: /Users/amit/Desktop/mule-trace

1. BACKEND ARCHITECTURE (FastAPI, Python 3.10+):
   - backend/config.py: Global thresholds (Structuring $10k line, risk tiers).
   - backend/requirements.txt: Dependencies (FastAPI, PyTorch, PyTorch Geometric, NetworkX).
   - backend/data/generator.py: Multi-pattern synthetic dataset generator (Structuring, Rapid Cashout, Mule Rings, Devices, IPs).
   - backend/graph/builder.py: NetworkX Unified Entity Graph builder (Accounts, Devices, IPs, Transfers).
   - backend/gnn/features.py: 10-feature extraction matrix per account node.
   - backend/gnn/dataset.py: NetworkX to PyTorch Geometric Data converter with train/val masks.
   - backend/gnn/model.py: Hybrid GraphSAGE + GAT neural network classifier.
   - backend/gnn/train.py: Weighted BCE training pipeline with validation AUC tracking.
   - backend/gnn/predict.py: Model inference & risk scoring engine.
   - backend/risk/patterns.py: Structuring ($9,000–$9,950 smurfing), Rapid Cash-Out, Shared Device/IP detectors.
   - backend/risk/engine.py: Master Risk Intelligence Engine aggregating GNN scores & pattern signals.
   - backend/risk/sanctions.py: Sanctions screening & high-risk jurisdiction compliance checker.
   - backend/xai/explainer.py: Gradient×Input feature attribution explainer.
   - backend/xai/report.py: FIU-IND compliant Suspicious Activity Report (SAR) payload generator.
   - backend/agent/planner.py: NLP intent parser & dynamic execution plan builder.
   - backend/agent/tools.py: Modular tool registry (EDA, Structuring, Aggregation Rules, Entity Lookup).
   - backend/agent/orchestrator.py: Master Agent Orchestrator coordinating dynamic execution plans.
   - backend/main.py: FastAPI entry point with CORS, SPA static mounting, and API routes.

2. FRONTEND ARCHITECTURE (React 19 + Vite + Cyberpunk Glassmorphism CSS):
   - frontend/package.json & vite.config.js: Node build setup.
   - frontend/src/index.css: Design system, dark mode tokens, neon status badges.
   - frontend/src/App.jsx: Main dashboard layout & tab navigator.
   - frontend/src/components/AgentWorkbench.jsx: Analyst Chat UI + Live Agent Execution Visualizer.
   - frontend/src/components/NetworkGraph.jsx: Interactive 2D force-directed graph inspector.
   - frontend/src/components/AccountsView.jsx: Account risk matrix & filters.
   - frontend/src/components/SarReportView.jsx: FIU-IND SAR Audit Report Viewer.
